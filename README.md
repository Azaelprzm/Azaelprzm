## 🚀 Proyectos destacados

<details open>
<summary><strong>📊 Minería de datos aplicada al riesgo de deserción estudiantil</strong></summary>

Proyecto de residencia profesional desarrollado con la metodología **CRISP-DM**. Incluye preparación e integración de datos, segmentación con K-Means, reglas de asociación con Apriori y un dashboard para comunicar resultados.

La versión pública utiliza datos sintéticos y documenta las decisiones de privacidad y uso responsable de la información.

**Tecnologías:** Python, pandas, NumPy, scikit-learn, Streamlit y Plotly.

[Ver repositorio →](https://github.com/Azaelprzm/educational-data-mining)
